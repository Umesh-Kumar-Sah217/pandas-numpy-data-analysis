# 📊 Pandas & NumPy Data Analysis Project

## About the Project
This project is part of my Data Analytics learning journey. I am practising Python, Pandas, and NumPy to develop practical data analysis skills.

The project includes a sample sales dataset and 19 practical questions covering data exploration, data manipulation, calculations, and statistical analysis.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Jupyter Notebook
- Microsoft Excel
- Git & GitHub

## 📋 Dataset Information
The dataset contains sales information with the following columns:
- `Order_ID`
- `City`
- `Product`
- `Qty`
- `Price`

## 📚 Topics Covered

### Pandas
- Reading and exploring datasets
- DataFrame operations
- Filtering and sorting
- Statistical calculations
- Grouping and aggregation
- Creating new columns
- Revenue calculations

### NumPy
- Creating NumPy arrays
- Mean and median
- Standard deviation
- Minimum and maximum
- Array calculations
- Boolean indexing
